你好，世界。这里是「十五的博客」的第一篇文章。

## 为什么开始写博客

想法其实很简单：把散落在笔记、聊天记录和脑子里的东西，整理成能被未来的自己重新读懂的文字。

写下来的过程本身就有价值。一个知识点只有能用自己的话讲清楚，才算真的理解；一段经历只有被好好记录，才不会随着时间变成模糊的轮廓。所以这个博客首先是写给自己的，如果恰好也能帮到你，那就更好了。

## 这里会有什么

- **技术笔记**：踩过的坑、读过的源码、好用的工具和工作流；
- **阅读与思考**：书、文章，以及由此延伸出去的一些想法；
- **生活记录**：值得记住的小事和阶段性的回顾。

内容会慢慢积累，不追热点，也不保证频率——比较想保持「有想写的再写」的状态。

## 关于这个站点

本站使用 [Astro](https://astro.build/) 构建，主题基于开源的 LogFlow Theme 二次配置，静态生成、没有后端，打开速度很快。

如果你也想在本地跑一个类似的站点：

```bash
npm install
npm run dev
```

更多细节可以看仓库里的 `README.md`。

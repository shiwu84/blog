### 你好，我是十五

一个在路上的计算机学习者。喜欢把东西拆开看看原理，也喜欢把折腾的过程记下来。

目前在关注几件事：

- **Rust**：从所有权、借用这些概念开始，一点点啃系统编程；
- **Linux 与网络**：折腾服务器、网络配置和各种命令行工具；
- **AI 工具与提示词**：试着让 AI 更好地参与学习和日常；
- **游戏开发**：用 Cocos Creator 做小游戏，也看看 Rust 生态里的桌面应用。

我习惯用 [Obsidian](https://obsidian.md/) 做原子笔记。对我来说，知识不是线性的，而是网状生长的：先动手实践、建立连接，再回头补底层的基础。

### 关于本站

这里会写 Rust 学习笔记、Linux / 服务器折腾记录、AI 实践，以及游戏开发中的一些想法，有时也会记一点日常。

本站使用 [Astro](https://astro.build/) 构建，主题基于开源的 [LogFlow Theme](https://github.com/kevynf/logflow-theme)（MIT 协议）二次配置；部署在自己的 Ubuntu 服务器上，由 GitHub Actions 自动构建发布。

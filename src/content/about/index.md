### 你好，我是十五

目前在做 Cocos Creator 游戏开发，业余时间关注 AI、Linux、Rust 和网络安全。喜欢把东西拆开看看原理，也喜欢把折腾的过程记下来。

最近在忙的事：

- **游戏开发**：用 Cocos Creator 做一个 2D 小游戏，折腾家具摆放、装修、角色换装、过场动画这些东西；
- **AI**：收集和试验各种提示词，试着让 AI 更好地参与学习和开发；
- **Linux 与网络**：配置服务器和网络、折腾命令行工具，偶尔自建点小服务；
- **Rust**：从所有权、借用这些概念开始，一点点啃系统编程，也想试试用 Rust 写桌面应用；
- **网络安全**：在看渗透测试的方法论，从 MITRE ATT&CK、OWASP WSTG 到 PTES。

我习惯用 [Obsidian](https://obsidian.md/) 做原子笔记。对我来说，知识不是线性的，而是网状生长的：先动手实践、建立连接，再回头补底层的基础。

### 关于本站

这里会写游戏开发记录、AI 使用与提示词实验、Linux / Rust 笔记、网络安全学习笔记，有时也记一点日常。

本站使用 [Astro](https://astro.build/) 构建，主题基于开源的 [LogFlow Theme](https://github.com/kevynf/logflow-theme)（MIT 协议）二次配置；部署在自己的 Ubuntu 服务器上，由 GitHub Actions 自动构建发布。
